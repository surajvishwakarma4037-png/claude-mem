# HealthScan Diagnostics

This is a demo diagnostic laboratory website built with Next.js and Tailwind CSS.

## Local development

1. Install dependencies: `npm install`
2. Run app: `npm run dev`
3. Open: http://localhost:3000

## Environment variables

Copy `.env.example` to `.env.local` and configure the optional admin credentials.

## Notes

- Example credentials are server-side only and not committed to frontend code.
- Prices, reviews and claims are fictional demo placeholders.
